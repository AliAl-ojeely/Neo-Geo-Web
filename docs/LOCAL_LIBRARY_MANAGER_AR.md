# مدير المكتبة المحلية

افتح المكتبة، واختر ROMs وPREVIEWS وملف neogeo.zip الداخلي، ثم اضغط «حفظ المكتبة». يمكن اختيار مجلد BIOS بدل الملف، أو سحب المجلد/الملف إلى زر القسم. لا تُرفع الملفات ولا يُطلب إذن كتابة. يمكن تغيير قسم واحد دون مسح القسمين الآخرين.

الموديولات في web/library. NGLocal يعرض init/select/save/scan/reconnect/forget/data. حالات الأقسام: granted، prompt، denied، missing، invalid، error، storage-error. عند prompt اضغط إعادة السماح؛ عند denied أعد اختيار القسم. لا تفتح الصفحة منتقي ملفات تلقائيًا.

الكتالوج العام يصف 127 نسخة مثبتة، منها 49 نسخة مشتقة. المكتبة الأصلية تعرض 78 ملفًا مطابق الحجم فقط؛ استخدم الحزمة المحضّرة لعرض النسخ الـ127. الفهرسة لا تعني نجاح الإقلاع: يُفحص SHA-256 كاملًا قبل التشغيل. الفهرس يقرأ metadata؛ ROM يُقرأ عند تشغيله فقط. لا تُنسخ المكتبة إلى IndexedDB.

نسيان المكتبة يمسح قاعدة مراجع المكتبة وحدها. لا يحذف الملفات أو قواعد حفظ EmulatorJS أو المفضلة أو إعدادات العرض. وضع Python الحالي باقٍ، وCSS والهوية البصرية محفوظان.
