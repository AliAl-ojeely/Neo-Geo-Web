Ready for Neo Geo?

Prepare these three local sources and link them to the player. No file uploads are needed.

ROMs

Required

Your game files. Extract the game package, then select the ROMs folder containing the ZIP games. Keep each game ZIP compressed.

PREVIEWS

Recommended

Previews help you recognize games in the library. Select the PREVIEWS folder after extracting the image package. Games work without previews.

BIOS

Required

Neo Geo system files required by FBNeo. Select neogeo.zip from the BIOS folder. Keep this inner ZIP compressed.
