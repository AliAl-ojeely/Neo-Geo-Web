Ready for Neo Geo?

Prepare these three local sources and link them to the player. No file uploads are needed.

ROMs

Required

Your game files. Extract the game package, then select the ROMs folder containing the ZIP games. Keep each game ZIP compressed.

PREVIEWS

Recommended

Previews help you recognize games in the library. Select the PREVIEWS folder after extracting the image package. Games work without previews.

BIOS

Required

Neo Geo system files required by FBNeo. Select neogeo.zip from the BIOS folder. Keep this inner ZIP compressed.

Keyboard Shortcuts

Useful shortcuts for playing Neo-Geo games in your browser.

Emulator shortcuts

+
Enter fullscreen

During gameplay, press + or Numpad +.

Tab
Pause / resume

Press Tab while the game is running.

Esc ×2
Return to library

Press Esc twice within two seconds while playing.

/
Search the library

On Home, press / to focus search; Esc clears it.

Default game controls

↑ ↓ ← →
Player 1 movement

Arrow keys move the first player.

A S D F
Player 1 buttons

Neo-Geo A, B, C, D in that order.

1 / 3
Start / coin

1 = Player 1 Start; 3 = Player 1 Coin.

Q R E
Player 1 combinations

Q = A+B, R = A+B+C, E = C+D.

Num 8/2/4/6
Player 2 defaults

Numpad movement; J/K/L/P for A/B/C/D; 2 = Start, 4 = Coin. Turn on Num Lock if needed.

Game bindings are customizable in Settings. Fullscreen is also available from the emulator toolbar; browser Escape may exit fullscreen first.
